# Security Policy

## Supported versions

Security fixes are provided for the latest version on the default branch.

## Reporting a vulnerability

Do not open a public issue or discussion for a suspected vulnerability. Use
GitHub's private vulnerability reporting form from the repository's **Security**
tab and select **Report a vulnerability**. GitHub Issues are intentionally
disabled for this repository.

Include the affected version, reproduction steps, potential impact, and any
suggested remediation. Do not include live credentials, private source
documents, or other sensitive data. Revoke and replace any credential that may
have been exposed.
